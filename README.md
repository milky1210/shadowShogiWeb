# 影将棋 Web

Swift版の `shadowShogi` を参照して移植したWeb版です。同じ画面での二人対局と、ブラウザだけで完結する3段階のCPU対局を遊べます。

## ゲームの特徴

- Swift版と同じ制約で初期配置をランダム生成
- 相手の駒は影だけを表示し、駒ごとに予想・あいまい予想を記録
- 予想画面では、その駒が実際に動いた軌跡を5×5の盤で確認
- 成り、持ち駒、駒打ち、二歩、行き所のない駒を判定
- 王を取った時点で勝敗決定（王手・詰み判定なし）
- 一手ごとに端末を相手へ渡すプライバシー画面
- CPUは初級（取れる駒を優先）、中級（影と棋譜から局面評価）、最強（全配置を把握して先読み）の3段階
- CPUの思考処理を含め、対局中の通信やバックエンドは不要

## 開発

```bash
npm install
npm run dev
```

テストと本番ビルド:

```bash
npm test
npm run build
```
